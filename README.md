# 🚀 Excelerate Mobile App

A modern Flutter application designed for accessing career programs, learning resources, and tracking professional growth. Built with clean architecture and responsive UI.

---

## ✨ Features

- **User Authentication:** 
  - Login Screen with form validation & password visibility toggle.
  - Sign Up Screen for new user registration.
- **Career Programs:** Explore top tech and data programs.
- **Clean Architecture:** Well-structured project with separate modules for screens, widgets, routes, and utilities.

---

## 🛠️ Tech Stack & Tools

- **Framework:** [Flutter](https://flutter.dev/) (Dart)
- **State Management:** StatefulWidget / Provider
- **Navigation:** Named Routes (`app_routes.dart`)
- **IDE:** Android Studio / VS Code
- **Version Control:** Git & GitHub

---

## 📁 Project Structure

```text
lib/
├── models/         # Data models
├── screens/        # UI Screens (Login, SignUp, MainWrapper, etc.)
├── utils/          # App colors, routes, and constants
├── widgets/        # Reusable custom UI components (CustomButton, etc.)
└── main.dart       # Entry point of the application
